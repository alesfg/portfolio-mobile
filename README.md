# Portfolio - Alejandro Flores González

Portfolio profesional de desarrollador de aplicaciones móviles creado con React, TypeScript, Tailwind CSS y Framer Motion.

## 🚀 Características

- **Diseño Moderno y Responsive**: Mobile-first con diseño adaptable a todos los dispositivos
- **Animaciones Fluidas**: Implementadas con Framer Motion para una experiencia premium
- **Múltiples Estilos Visuales**:
  - Dark mode profesional con acentos neón
  - Glassmorphism (efecto de vidrio translúcido)
  - Gradientes sutiles
  - Tema tech/futurista
  - Neumorfismo
  - Bold & colorful

## 🛠️ Tecnologías

- **React 18** - Framework de UI
- **TypeScript** - Tipado estático
- **Tailwind CSS** - Estilos y diseño
- **Framer Motion** - Animaciones
- **Vite** - Build tool optimizado
- **React Icons** - Iconografía

## 📦 Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Construir para producción
npm run build

# Previsualizar build de producción
npm run preview
```

## 📱 Secciones del Portfolio

1. **Hero/Banner** - Presentación impactante con información clave
2. **Sobre Mí** - Biografía profesional con efecto glassmorphism
3. **Proyectos** - Galería de aplicaciones con detalles y enlaces
4. **Habilidades** - Tecnologías y nivel de experiencia
5. **Testimonios** - Reseñas de clientes con diseño neumórfico
6. **Contacto** - CTA principal para contratación
7. **Footer** - Enlaces a redes sociales

## 🎨 Personalización

Para personalizar el portfolio:

1. Edita la información personal en `src/App.tsx`
2. Modifica los colores en `tailwind.config.js`
3. Actualiza las apps en el array `apps`
4. Cambia las habilidades en el array `skills`
5. Edita los testimonios en el array `testimonials`
